# 🍕 Pizza Merk

Ein Merkspiel im Browser: Kunden bestellen Pizza, du merkst dir die Zutaten und belegst sie aus dem Kopf. Wie viele Kunden schaffst du?

## ▶️ Jetzt spielen

👉 https://tillwassenhoven1-glitch.github.io/Pizza-Bestellung-/

Keine Installation, kein Konto nötig – läuft auf Handy, iPad und PC. 🎮 Version 0.1 · Open Beta

## So funktioniert's

- 👀 Ein Kunde kommt und bestellt – merk dir die Zutaten!
- 🙈 Nach ein paar Sekunden wird die Bestellung verdeckt (oder du klickst auf „Gemerkt!“)
- 🍅 Beleg die Pizza aus dem Kopf – die Reihenfolge ist egal
- 📈 Kunde 1 will 1 Zutat, Kunde 2 will 2, Kunde 3 will 3 … es wird immer schwerer
- 💥 Eine falsche Zutat oder eine zu viel? Dann geht's zurück zu Kunde 1!

## Features

- 🎲 Jede Bestellung ist zufällig – keine Runde ist wie die andere
- 🥫 16 Zutaten: Tomate, Käse, Pilze, Paprika, Zwiebel, Oliven, Mais, Ananas, Speck, Peperoni, Garnele, Spinat, Schinken, Thunfisch, Knoblauch & Ei
- 🔢 Bei großen Bestellungen kommen Zutaten auch doppelt vor (z. B. „2× 🍄 Pilze“)
- ⏱️ Merk-Timer, der mit jedem Kunden länger wird
- 🍕 Die Zutaten landen wirklich auf der Pizza
- 😡 Bei einem Fehler siehst du, was der Kunde eigentlich bestellt hatte
- 🧑‍🍳 Immer neue Kunden mit unterschiedlichen Gesichtern und Namen
- 🏆 Rekord wird in deinem Browser gespeichert
- 🔊 Sounds für Belegen, Erfolg und Fehler
- 📲 Touch-Steuerung fürs Handy/iPad – oder Maus am PC

## Steuerung

| Aktion | So geht's |
|---|---|
| Zutat belegen | Auf die Zutat tippen/klicken |
| Bestellung früher verdecken | „Gemerkt! ✔“ |
| Neue Runde | „Von vorne 🔁“ |
